# NOVA GEMOY SELF-HEAL

Bot web **cewe cantik & gemoy** yang bisa memperbaiki dirinya sendiri.

Saat diserang dia panik dulu, lalu pergi ke komputer, memperbaiki error, menambah keamanan, terus senyum dingin dan bilang:

> "Aku senang ada yang menghargaiku dan suka menyerangku... ayo nanti serang lagi, aku menunggu."

## Fitur

- Avatar cewe gemoy (3D)
- Mode **Panic → Repair → Taunt** dengan visual yang beda-beda
- Self-hardening: semakin sering diserang, filter semakin ketat
- Memori percakapan
- Banyak variasi respons
- Siap deploy ke Cloudflare Pages

## Cara Pakai

1. Buka `index.html`
2. Chat biasa
3. Tekan tombol **Simulasikan Serangan** untuk lihat dia panik lalu memperbaiki diri

## Deploy Cloudflare

Pages → Connect repo ini → Deploy (static site).
